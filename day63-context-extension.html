AIFROMZERO · DAY 63

📏 Context extension — a model trained at 4k tokens does not "get confused" past 4k, it breaks, and the reason is arithmetic you can watch happen. RoPE encodes position as a rotation whose angle is m·θi; attention then depends only on the relative angle (m−n)·θi. Every relative distance the model has ever seen lies in [0, L). Ask for position 8000 on a 4k model and the low-frequency dimensions are rotated into angles that never appeared in training — this page computes exactly how many, and plots the attention-score decay collapsing. Then the three fixes, all implemented and measured: Position Interpolation (squeeze positions back into the trained range — and pay for it in the high frequencies that encode local order), NTK-aware scaling (change the base so high frequencies are barely touched), and YaRN (interpolate by wavelength, per dimension, so only the dimensions that need it are squeezed). Every curve is computed here from real rotations.

Scale factor 4×. Everything below is computed from real RoPE rotations at these settings — no pretrained weights, no cached results.

PROVE THE ROTATION IS RELATIVE

The whole scheme rests on one identity: the rotated dot product depends only on m−n, never on m and n separately. If that fails, none of the rest means anything. This checks it on random vectors. 


      


    

  






  

    


      
Position is an angle, and angles wrap


      
RoPE does not add a position vector. It rotates each pair of dimensions by an angle
      proportional to the position:

      
θ_i = base^(-2i/d)          for dimension pair i
angle at position m  =  m · θ_i


      
Rotate the query by m·θ and the key by n·θ, and their dot product
      depends only on (m−n)·θ. Absolute position vanishes; only distance survives. That
      is the elegant part, and the MEASURE tab checks it rather than assuming it.


      
What actually breaks past the trained length

      
Each dimension has a wavelength — the distance over which it completes a full rotation:

      
λ_i = 2π / θ_i = 2π · base^(2i/d)

      
Fast dimensions (small i) have short wavelengths and cycle many times inside the
      training window, so the model has seen every angle they can produce. Slow dimensions have
      wavelengths longer than the entire training context — at base 10000 and d=64, the
      slowest wavelength is tens of thousands of tokens. Inside a 2k window those dimensions only ever
      swept a small arc.


      

        
So extrapolating to position 8000 asks those dimensions for angles from a
        region the model has never seen. This is not gradual degradation. The
        attention decay curve stops being monotone and goes erratic, which is why naive extrapolation
        produces confident nonsense rather than slightly worse output.

      


      
Fix 1 — Position Interpolation (Chen et al., 2023)

      
Do not extrapolate. Compress: to serve length L′ on a model trained at L,
      divide every position by s = L′/L. Position 8000 becomes 2000, which is inside the
      trained range. Nothing is ever asked for an unseen angle.

      
The cost lands on the high frequencies. Adjacent tokens used to be θ₀ apart and
      are now θ₀/s apart — at 4× extension, adjacent tokens are four times harder to tell
      apart in exactly the dimensions that encode local word order. That is why PI usually needs a
      little finetuning to recover.


      
Fix 2 — NTK-aware scaling

      
PI squeezes every dimension equally, which is the wrong instinct: the high frequencies were
      never the problem. NTK-aware scaling instead raises the base:

      
base' = base · s^(d/(d−2))

      
This barely changes the fastest dimensions while stretching the slow ones a lot — spreading
      the interpolation across frequencies rather than applying it uniformly. It often works with no
      finetuning at all, which is why it spread through the community as a config tweak before it had
      a paper.


      
Fix 3 — YaRN (Peng et al., 2023)

      
YaRN makes the per-dimension decision explicit. Compute each dimension's wavelength and:

      
    
        
  • λ ≪ L — many cycles inside training. Leave it alone.
    • 
        
  • λ ≫ L — never completed a cycle. Interpolate fully.
    • 
        
  • in between — ramp smoothly between the two.
    • 
      

      
Plus a small attention-temperature correction, because changing the angle distribution
      changes the entropy of the softmax. The result keeps local resolution where PI loses it, which
      the table on the MEASURE tab shows numerically.


      
What none of this fixes

      
Every method here is about making positions representable. None of them teaches the
      model to use information at 30k tokens — that is a data and training question, and it
      is why a model advertising a large window can still fail a needle test in the middle of it.
      Extending the context and using the context are two different problems, and the fixes on this
      page only address the first.


    

  






  

    


      
🔨 Build it yourself


      
1. RoPE frequencies

      
function ropeFreqs(d, base){
  const th = [];
  for (let i = 0; i < d / 2; i++) th.push(Math.pow(base, -2 * i / d));
  return th;                                  // th[0] fastest, th[last] slowest
}
const wavelength = t => 2 * Math.PI / t;


      
2. Rotate a vector by a position

      
function ropeApply(vec, pos, th){
  const out = vec.slice();
  for (let i = 0; i < th.length; i++){
    const a = pos * th[i], c = Math.cos(a), s = Math.sin(a);
    const x = vec[2*i], y = vec[2*i+1];
    out[2*i]   = x * c - y * s;
    out[2*i+1] = x * s + y * c;
  }
  return out;
}


      
3. Check the relative-position identity before anything else

      
// dot(rope(q,m), rope(k,n)) must equal dot(rope(q,m-n), rope(k,0))
const a = dot(ropeApply(q, m, th), ropeApply(k, n, th));
const b = dot(ropeApply(q, m - n, th), ropeApply(k, 0, th));
assert(Math.abs(a - b) < 1e-9);

      
Everything else assumes this. Five thousand random pairs cost nothing and it is the one
      identity that makes RoPE what it is.


      
4. Count what actually goes out of range

      
function outOfRange(d, base, L){
  return ropeFreqs(d, base).filter(t => wavelength(t) > L).length;
}

      
This is the diagnosis, and it is two lines. Dimensions whose wavelength exceeds the training
      length never completed a rotation, so they are the ones asked for unseen angles.


      
5. The three methods, as position or frequency transforms

      
// Position Interpolation: squeeze the POSITION
const piPos = (pos, s) => pos / s;

// NTK-aware: change the BASE, leave positions alone
const ntkBase = (base, s, d) => base * Math.pow(s, d / (d - 2));

// YaRN: per-dimension ramp by wavelength
function yarnScale(th, L, s, lo, hi){
  return th.map(t => {
    const r = L / wavelength(t);           // cycles completed inside training
    if (r > hi) return t;                  // plenty of cycles: leave alone
    if (r < lo) return t / s;              // never cycled: interpolate fully
    const g = (r - lo) / (hi - lo);        // ramp between
    return t / (s * (1 - g) + g);
  });
}


      
6. Measure the decay curve rather than describing it

      
function decayCurve(th, maxDist, samples){
  const out = [];
  for (let dist = 0; dist < maxDist; dist += step){
    let acc = 0;
    for (let s = 0; s < samples; s++){
      const q = randVec(d), k = randVec(d);
      acc += dot(ropeApply(q, dist, th), ropeApply(k, 0, th));
    }
    out.push(acc / samples);
  }
  return out;
}

      
Plot it for each method. The naive-extrapolation curve stops being monotone past L, and that
      is the picture worth having.


      
7. State the cost, do not bury it

      
// adjacent-token angle gap in the FASTEST dimension - local word order
const localGapPI   = th[0] / s;      // PI: divided by the full scale factor
const localGapYaRN = yarnScale(th, L, s, 1, 32)[0];   // usually ~ th[0]

      
Report both. A method that extends context by destroying local resolution has not extended
      anything useful, and the number that shows it is one division.
